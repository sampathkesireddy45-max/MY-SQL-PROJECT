# Digital Payment Fraud Detection System

## About the Project

Digital payments have become a part of our daily lives. We use UPI, debit cards, credit cards and net banking for almost everything. But as digital payments increase, the chances of payment fraud also increase.

I created this project using **MySQL** to organize digital payment data and analyze transactions that may involve suspicious activities.

The main aim of this project is to understand how a database can be designed and how SQL queries can be used to analyze payment transactions and fraud-related information.

## What This Project Includes

- Customer and bank account details
- Merchant and payment method information
- Digital payment transaction records
- Registered devices and transaction locations
- Fraud detection rules
- Transaction risk assessments
- Fraud alerts and investigation records
- Chargeback and login activity details

## Database Design

The database contains **15 tables**, connected using primary keys and foreign keys.

During this project, I worked with:

- Database and table creation
